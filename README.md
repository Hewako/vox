# Vox

**Локальная расшифровка аудио и видео в текст.**

> Приложение собирается локально на вашем Mac. Готового установщика для
> скачивания нет — это сделано специально, чтобы вы видели весь код
> и запускали только то, что собрали сами.

Vox — это настольное приложение для macOS, которое превращает речь в текст
полностью на вашем компьютере. Без облаков, без подписок, без утечек данных.

Внутри — движок whisper.cpp на чипе Apple Silicon (M1/M2/M3/M4), поэтому
расшифровка идёт в 5–15 раз быстрее реального времени.

## Что умеет

- 🎙️ **Расшифровка аудио и видео** — MP4, MOV, MKV, MP3, WAV, M4A и другие
- 🌍 **99 языков** — все, что поддерживает Whisper, с автоопределением или ручным выбором
- ⚡ **Локально** — файлы не покидают ваш Mac
- 🎯 **VAD** — убирает тишину, снижает галлюцинации Whisper
- 📝 **SRT-субтитры** — сохраняет рядом с текстом
- 🔁 **Пакетная обработка** — можно бросить сразу несколько файлов
- 💾 **Кэш** — повторная расшифровка того же файла мгновенна
- 🖱️ **Drag & Drop** — файлы можно перетаскивать прямо в список

## Системные требования

- macOS 11+ (Big Sur или новее)
- Apple Silicon (M1/M2/M3/M4) — рекомендуется
- 8 ГБ ОЗУ и больше
- 2 ГБ свободного места под модель Whisper

## Установка

### 1. Установите Homebrew (если нет)

~~~bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
~~~

### 2. Установите зависимости

~~~bash
brew install whisper-cpp ffmpeg
~~~

### 3. Получите Vox.app

**Если вы получили Vox.app от автора** — просто перетащите его в папку Программы.

**Если собираете сами** — см. раздел «Сборка из исходников» ниже.

### 4. Первый запуск

Откройте Vox. Если моделей Whisper нет — приложение предложит скачать
их автоматически (~1.5 ГБ).

## Использование

1. **Добавьте файлы** — кнопкой или перетащите в список.
2. **Настройте** — язык, модель, VAD, SRT.
3. **Нажмите «Расшифровать»**.
4. **Заберите результат** — рядом с видео появится .txt (и .srt, если включено).

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| Esc | Отменить текущую расшифровку |

## Где хранятся данные

| Что | Где |
|-----|-----|
| Модели Whisper | ~/whisper-models/ |
| Кэш расшифровок | ~/.whisper_cache/ (до 500 МБ) |
| Настройки | ~/Library/Application Support/Vox/settings.json |
| Логи | ~/Library/Logs/Vox.log |

Кэш автоматически чистится, когда превышает 500 МБ. Можно очистить вручную
через кнопку «Очистить кэш» в самом приложении.

## Сборка из исходников

~~~bash
# 1. Скачайте исходники (или склонируйте репозиторий, если он есть)
cd ~/Desktop
git clone <ваш-репозиторий> vox    # или распакуйте архив с исходниками

# 2. Установите сборщик
pip3 install py2app tkinterdnd2

# 3. Соберите приложение
cd vox
python3 setup.py py2app

# 4. Скопируйте в Программы
cp -R dist/Vox.app /Applications/
~~~

Готовый .app появится в папке dist/.
