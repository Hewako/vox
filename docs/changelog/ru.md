# История изменений

Все значимые изменения в Vox описаны в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/spec/v2.0.0.html).

## [1.1.3] - 2026-10-01

> **Обновление с 1.1.2 вручную.** Из-за ошибки в апдейтере 1.1.2
> автообновление с неё невозможно. Скачайте Vox_1.1.3.app.zip вручную.
> С версии 1.1.3 и выше автообновление работает корректно.

### Исправлено
- Диалог обновления падал с `NameError` при любой ошибке после
  завершения скачивания.
- Кнопки «Открыть на GitHub» и «Закрыть» в состоянии ошибки не
  реагировали — виджеты оставались выключенными.

### Изменено
- Диалог обновления теперь применяет обновление сразу после
  скачивания; промежуточная кнопка «Готово» убрана.
- При успехе диалог показывает «Установлено», и Vox перезапускается
  автоматически с новой версией.
- При ошибке диалог остаётся открытым, показывает код ошибки и
  открывает в браузере соответствующий раздел ERROR_CODES.md на GitHub.

## [1.1.2] - 2026-10-01

### Добавлено
- Окно «Коды ошибок»: каждый сбой в Vox имеет короткий код (E001-E099).
  В окне перечислены все коды с локализованными описаниями, а каждый
  код — кликабельная ссылка на свой раздел в ERROR_CODES.md на GitHub.
- Файл ERROR_CODES.md с отдельным разделом на каждый код и подсказками.
- Локализованный префикс «Ошибка», используемый в диалогах и в истории.

### Изменено
- Окно обновления теперь имеет три фазы: Готово → Скачивание → Скачано
  → Установка. После скачивания появляется одна зелёная кнопка «Готово»;
  файл применяется только по этому клику.

## [1.1.1] - 2026-10-01

### Исправлено
- Исправлен отсутствующий модуль Pillow (PIL) в собранном .app. Версия 1.1.0
  не запускалась, потому что PIL был исключён при сборке.

## [1.1.0] - 2026-10-01

### Добавлено
- Автообновление с GitHub Releases: приложение проверяет новую версию при запуске и устанавливает её в один клик.
- Окно истории: каждая расшифровка сохраняется вместе с результатом. Можно открыть, повторить или удалить любую запись.
- Окно настроек: все параметры вынесены в отдельное модальное окно с кнопками Применить и Отмена.
- Окно истории изменений: полный список версий доступен из окна «О программе».
- Коды ошибок E001-E099: сбои классифицируются для упрощения диагностики.
- Ротация логов: Vox.log ротируется при достижении 1 МБ, хранятся 5 резервных копий.

### Изменено
- Главное окно стало чище: настройки переехали в отдельное окно.
- Список истории переписан на Canvas для надёжного отображения иконок на macOS.
- Иконки статуса в истории окрашены: зелёный (успех) и красный (ошибка).

### Исправлено
- Исправлен импорт get_icon_base64 в окне splash.
- Исправлено сохранение настроек при закрытии.
- Удалён устаревший ключ theme из старых файлов настроек.

## [1.0.0] - 2026-09-29

### Добавлено
- Первый релиз.
- Локальная расшифровка аудио и видео через whisper.cpp.
- Поддержка 99 языков с автоматическим определением.
- VAD для удаления тишины и снижения галлюцинаций.
- Экспорт в SRT-субтитры.
- Пакетная обработка до 4 файлов параллельно.
- Кэш для повторных расшифровок.
- Поддержка drag & drop.
- 12 языков интерфейса.
- Мастер первого запуска для загрузки моделей Whisper.
